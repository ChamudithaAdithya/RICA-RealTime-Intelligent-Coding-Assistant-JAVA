## How To Use This Map

1. Find the RICA code shown in the editor or violations panel.
2. Open the linked rule page for the exact trigger, example, and fix steps.
3. Use the concept links to understand the architecture vocabulary behind the recommendation.
4. Return to the rule page and apply the smallest refactor that fixes the responsibility or dependency problem.
