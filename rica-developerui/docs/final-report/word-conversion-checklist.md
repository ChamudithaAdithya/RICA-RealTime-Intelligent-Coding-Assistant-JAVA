# Word Conversion Checklist

Use this checklist when converting `final-report.md` into the final dissertation DOCX.

## Required Formatting

- Font: Times New Roman
- Font size: 12 pt body text
- Line spacing: 1.5
- Margins: 1 inch on all sides
- Referencing: IEEE
- Page numbers: enabled from the main document body according to university rules
- Headings: Word Heading 1, Heading 2, Heading 3 styles
- Captions: Word captions for figures and tables
- Table of Contents: generated from Word heading styles
- List of Figures: generated from Word figure captions
- List of Tables: generated from Word table captions

## Recommended Conversion Steps

1. Open `final-report.md`.
2. Copy the content into Microsoft Word or convert through a trusted Markdown-to-DOCX tool.
3. Apply Times New Roman, 12 pt, and 1.5 line spacing to Normal style.
4. Apply Word Heading styles to all chapter and section headings.
5. Insert the copied figure images from `docs/final-report/figures`.
6. Add captions using Word's References > Insert Caption feature.
7. Generate the Table of Contents.
8. Generate the List of Figures and List of Tables.
9. Check that references use IEEE numeric ordering.
10. Export both DOCX and PDF.
